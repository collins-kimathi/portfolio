🌟 Portfolio Website

A modern, responsive personal portfolio website showcasing my projects, skills, and professional experience.



🎯 About

This portfolio website is designed to showcase my work, skills, and experience in web development. It features a clean, modern design with smooth animations and an intuitive user interface.

 ✨ Features

- Responsive Design - Fully responsive and mobile-friendly
- Dark/Light Mode - Toggle between dark and light themes with persistent storage
- Smooth Animations - Engaging scroll animations and transitions
- One-Page Navigation - Smooth scrolling to different sections
- Color Customization - Multiple color schemes to choose from
- Interactive Elements - Spotlight effects and dynamic interactions
- Fixed Header - Navigation bar that sticks on scroll
- Mobile Menu - Optimized mobile navigation experience
- Tab Slide Effects - Smooth tab transitions
- Split Text Animations - Creative text reveal animations

 🛠️ Technologies Used

- HTML5 - Semantic markup
- CSS3 - Custom styling with modern CSS features
- JavaScript (jQuery) - Interactive functionality
- Swiper.js - Touch slider functionality
- Splitting.js - Text animation effects
- Font Awesome - Icon library
- Google Fonts - Custom typography

 🚀 Getting Started

These instructions will help you get a copy of the project up and running on your local machine.

 Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git installed on your machine
- A code editor (VS Code, Sublime Text, etc.)
- Basic knowledge of HTML, CSS, and JavaScript

📥 Installation

1. Clone the repository
   bash
   git clone https://github.com/collins-kimathi/portfolio.git
   

2. Navigate to the project directory
   bash
   cd portfolio
  

3. Open in your code editor
   bash
   code .
   
   Or open the folder in your preferred code editor.

4. Launch the website
   - Simply open index.html in your web browser
   - Or use a local development server:
     bash
     - If you have Python installed
     python -m http.server 8000
     
     - If you have Node.js installed
     npx serve
     

💻 Usage

Viewing the Website

1. Open index.html in your browser
2. Navigate through different sections using the menu
3. Toggle dark/light mode using the theme switcher
4. Explore different color schemes in the settings panel
5. Check responsiveness by resizing your browser window

🎨 Customization

Changing Colors

1. Open `js/main.js`
2. Locate the `settings_color()` function
3. Modify color variables or add new color schemes

Updating Content

1. Open `index.html`
2. Edit the text content in each section
3. Update images by replacing files in the images/ folder
4. Add your own projects, skills, and experience

 Adding Sections

1. Create a new section in index.html
2. Style it in css/styles.css
3. Add navigation link in the menu
4. Update JavaScript if interactive functionality is needed

Theme Customization

Edit the CSS variables in styles.css
css
root {
  --primary-color: #your-color;
  --background-color: #your-color;
  --text-color: #your-color;
}
